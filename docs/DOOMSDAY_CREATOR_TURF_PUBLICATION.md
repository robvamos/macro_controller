# Doomsday Creator Turf Publication Branch

## Purpose

This branch defines a priority expansion for `DDGameAss`: turn the project from a local Doomsday assistant into a creator-aware multimedia production companion for `Doomsday: Last Survivors`.

The goal is to help the project:

- join the official `Creator Turf` context
- produce multimedia content about the game on a recurring basis
- prepare creator submissions and community posts
- reuse local automation, OCR, visual capture, and game knowledge to speed up content production

## Official Context Confirmed

As of `2026-05-30`, the official `Doomsday: Last Survivors` site exposes:

- `CREATOR TURF`
- tag line: `WIN THE PRIZE FOR YOUR CREATIVITY`
- call to action: `Join Now`
- creator entry point: `https://dls.igg.com/creatorspace/?lang=eng`

Official community and distribution channels visible from the official site:

- Discord: `https://discord.gg/doomsdaylastsurvivors`
- TikTok: `https://www.tiktok.com/@doomsdaylastsurvivor`
- Facebook: `https://www.facebook.com/DoomsdayLastSurvivors`
- YouTube: `https://www.youtube.com/channel/UCh3yKGArimXH1VfJ2sTTaww`
- Instagram: `https://www.instagram.com/doomsdaylastsurvivorsofficial/`

The creator portal is an authenticated IGG experience and exposes a `passportSettings` block with login methods for:

- `phone`
- `mail`
- `id`
- plus third-party login options

This strongly suggests that the real creator workflow starts from:

1. IGG account access
2. creator portal access
3. content participation or submission flow inside `Creator Turf`

## Priority Recommendation

`DDGameAss` should treat Creator Turf as a first-class strategic path, not as a side note.

Reason:

- the game itself officially rewards creativity
- the project already owns useful primitives for repeatable content production
- Doomsday gameplay is visually rich and event-driven, which suits short-form and explainers
- the assistant can automate capture, asset normalization, OCR extraction, and tactical overlays better than a generic creator workflow

## Minimum Creator Workflow

1. Create or confirm the IGG account used for creator participation.
2. Access `https://dls.igg.com/creatorspace/?lang=eng`.
3. Build a local `creator identity kit`:
   - channel handles
   - content niches
   - language
   - publishing cadence
4. Prepare first production tracks:
   - beginner guides
   - hero spotlights
   - event explainers
   - short visual clips
5. Track what the community responds to best.
6. Feed those results back into the project as performance scores.
