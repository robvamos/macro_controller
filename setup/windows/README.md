# Windows Setup

Questa cartella è il punto di partenza per il setup Windows dell'app.

## Cosa contiene

- script di build
- app manifest Windows
- note operative per installer e aggiornamenti

## Obiettivo iniziale

Preparare un pacchetto installabile che:

- avvii `gui_macro_manager.py`
- possa richiedere elevazione quando serve
- preservi `config/` e `data/`
- includa gli asset di catalogo del gioco
